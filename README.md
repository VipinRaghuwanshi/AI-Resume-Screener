# AI Resume Screener 🚀

Live Demo: https://ai-resume-screener-swart.vercel.app/

AI Resume Screener is a smart ATS-style resume analysis tool that compares resumes with job descriptions and finds the best matching candidates.

## ✨ Features

- Resume vs Job Description Matching
- AI-style Candidate Scoring
- Skill Match Detection
- Missing Skills Detection
- Experience & Location Matching
- Multiple Resume Screening
- Strong / Maybe / Skip Candidate Filtering
- PDF Resume Upload Support
- Drag & Drop Resume Upload
- Modern Dashboard UI
- ATS-style Score Breakdown

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- PDF Parsing
- AI Matching Logic

## 📌 How It Works

1. Upload one or multiple resumes
2. Paste the Job Description
3. System extracts resume data
4. Skills and experience are compared with JD
5. Candidates get ATS-style scores
6. Best matching candidates are displayed

## 📊 Candidate Analysis Includes

- Skills Match
- Missing Skills
- Experience Match
- Location Match
- Education Details
- Overall ATS Score
